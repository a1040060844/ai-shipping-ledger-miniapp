# 产品范围：AI 发货台账

## 核心流程

发货单照片 / PDF
→ 原始文件不可变保存
→ 图像预处理
→ OCR
→ 多模态 AI 看原图复核
→ 产品库 / SKU / 工厂历史检索
→ 业务规则交叉验证
→ 自动记录高可信字段
→ 仅对低可信字段请求人工确认
→ 结构化台账
→ 统计 / 导出 / 原图追溯

## 明确不做

V1 不做“确认发货”“审批”“出库工作流”。系统只负责记录、修正、统计和追溯。

## 关键原则

### 原图优先

当前单据原图是最高优先级证据。历史记录只能辅助，不能覆盖本次真实数量。

### AI 不负责算账

AI 只提取：箱数、每箱数量、规格等原始字段。
总件数必须由确定性程序计算。

### 产品字段可以强检索，交易字段必须保守

SKU、产品名、规格、颜色、款式可以高权重匹配历史产品库。
箱数、日期、单据号、金额等本次交易字段必须主要依据当前原图。

### 原始明细与统计汇总分离

同一 SKU 可能在“前面 / 后面”分别出现。原始行必须完整保存，但统计时允许按规则聚合。
