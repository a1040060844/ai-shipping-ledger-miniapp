# UI V1：移动端发货台账

这一版 UI 不做“手机 Excel”，而是围绕三个高频动作设计：上传原单、快速处理少量不确定字段、查历史/看统计。

## 导航

- 发货：首页、上传入口、待复核提醒、最近记录
- 台账：搜索、月份筛选、状态筛选、历史记录
- 统计：按月份查看发货单/箱数/件数，以及工厂/商品汇总
- 产品：从历史发货记录形成商品视图，为后续正式产品主数据管理做入口

## 视觉原则

- 轻量、克制、偏业务工具，不做表格密集界面
- 主操作采用绿色，风险/待复核采用琥珀色
- 数量信息大字号展示，原始文字降级为辅助证据
- 待人工介入精确到字段，不要求整张单再次确认
- 原始发货单始终保持明显入口

## 详情页

一张发货单从上到下：

1. 状态与总量
2. 待处理提醒（仅存在疑点时显示）
3. 查看原始发货单
4. 单据信息
5. 商品卡片
6. 原单文字证据
7. 可编辑字段
8. 程序计算结果

人工修改字段后自动保存，不增加“确认发货”步骤。
